# Examples

This directory contains public, machine-neutral examples for adapting Portable Project Bootstrap to your own environment.

Included examples:

- `default.profile.json`
  A sample workspace profile with placeholder paths. Replace every placeholder with real absolute paths on your own machine.
- `workspace-layout.md`
  A generic workspace layout and the standard brand-new vs existing-project workflows.

These examples are intentionally not tied to the original author's machine.
